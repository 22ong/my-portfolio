### 3.1 높이 확인
히어로 높이 = 900 − 헤더 72 = **828px**.

| 요소 | 높이(약) |
|---|---|
| 3D 로고 (폭 800) | 151 |
| 로고 ↔ 이름 간격 + 이름 | 16 + 24 |
| 이름 ↔ 제목 간격 | 40 |
| 제목 2줄 (72 × 1.15 × 2) | 166 |
| 소개 + 간격 | 56 |
| 버튼 + 간격 | 88 |
| **합계** | **약 541** |

→ 남는 약 290px를 위아래 여백과 스크롤 화살표가 나눠 씀. 제목은 한 줄 최대 약 1,100px로 **2줄 유지** 가능(본문 최대 폭 1120~1200px 안).

## 5. 접근성·검색 메모
- h1이 로고("My Portfolio")라 **h1에 직무 정보가 없다.** 보완(`<title>`, meta description)은 마감 단계에서 정한다 (H14). 현재 `<title>`은 `my-portfolio`
- 제목 문구는 h1 바로 뒤 본문으로 두어 스크린 리더가 이어서 읽게 한다
- 장식(별·하트)은 `aria-hidden="true"` — 의미 없는 그림
- 스크롤 화살표는 `#projects` 링크로 만들고, 글자가 없으므로 `aria-label="프로젝트로 이동"` 🟡
- 배경 그라데이션 위의 회색 소개 문구도 명도 대비 4.5:1 이상을 유지한다 (6.3)
- `prefers-reduced-motion: reduce`이면 로고·장식 떠다님, 기울기, 화살표 움직임을 모두 끈다

## 16. 접근성 메모
- 뒷면 안에 링크(프로젝트 제목)가 있으므로 **타일 전체를 링크 하나로 감싸지 않는다** (링크 안에 링크 불가). 앞면 카테고리 이름을 링크로 만들고 CSS로 클릭 영역을 타일 전체로 넓힌 뒤, 뒷면 제목 링크는 그 위에 올린다
- 키보드: 타일 안으로 포커스가 들어오면(`:focus-within`) 뒤집힘 → Tab으로 뒷면 제목 링크까지 이동할 수 있음. 포커스 링은 강조색
- 앞면이 보이는 동안에는 뒷면 링크가 마우스로 눌리지 않게 막는다
- 스크린 리더는 회전과 상관없이 앞면 → 뒷면 순서로 읽음 (카테고리 이름 → 개수 → 프로젝트 제목들)
- 별은 `aria-hidden="true"`
- `prefers-reduced-motion: reduce`이면 회전 없이 앞·뒷면을 바로 바꾸고, 별은 움직임 없이 나타났다 사라진다
- 터치 기기에서는 뒷면을 쓰지 않으므로 앞면 링크만 동작
